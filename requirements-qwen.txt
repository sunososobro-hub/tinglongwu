# llama.cpp engines: Hy-MT2 (GPU default, --engine auto) and opt-in Qwen (--engine qwen). Needs a CUDA build of llama-cpp-python.
# The plain PyPI package has no Windows binary and would try to compile (needs Visual Studio + CUDA toolkit),
# so install the prebuilt CUDA wheel from the project's own index, binary only:
#   pip install -r requirements-qwen.txt --only-binary=:all:
# (install.ps1 does this for you.)
# Index variant matters (issue #74): the 0.3.36 Windows wheel on cu125 was compiled with AVX-512 and dies with
# "Windows Error 0xc000001d" (illegal instruction) on CPUs without it (e.g. Intel 12th-14th gen). The cu124
# wheel of the same version is AVX2-only and runs with the same CUDA 12 runtime DLLs (requirements-gpu.txt).
# Check an install with: tlwu-setup --check-llama
# If no wheel fits your Python/OS, skip it: tlwu falls back to the OPUS engine.
--extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu124
llama-cpp-python==0.3.36

Moved from the README (#347). The README shows charts only; this page holds the text. It is also published at https://sunososobro-hub.github.io/tinglongwu/docs.html.

tinglongWu (Taiwanese 聽攏有, thiann lóng ū: "I understood it all") is real-time speech translation, offline at runtime and verifiable. Install and model download need the network; the in-process guard is defence in depth, not proof (see Privacy, "Privacy model").

Example output:

[RU] Привет, как дела? [EN] Hello, how are you? [ZH] 你好，你過得怎麼樣？

Install

OS Command
Windows 10/11 (64-bit) Download tinglongwu-setup.exe, run it, accept the license, then keep clicking Next
macOS curl -fsSL https://github.com/sunososobro-hub/tinglongwu/releases/latest/download/mac_install.sh | bash
Linux (x86_64, Ubuntu 24.04 tested) curl -fsSL https://github.com/sunososobro-hub/tinglongwu/releases/latest/download/install.sh | bash

Unattended Linux (apt yes + default models): curl -fsSL https://github.com/sunososobro-hub/tinglongwu/releases/latest/download/install.sh | TLWU_YES=1 bash. More (checksums, ZIP, GPU): install.
